Uma aplicação web moderna para gerenciar e acompanhar pedidos de hambúrgueres. O StalkerBurguer oferece uma experiência intuitiva e responsiva para clientes e gerenciadores de estabelecimentos.

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter instalado:

- **Node.js** (versão 18+ recomendada)
- **npm**, **yarn**, **pnpm** ou **bun**

---

## 🔧 Instalação e Setup

### 1. Clone o repositório

```bash
git clone https://github.com/cauaprs92/StalkerBurguer.git
cd StalkerBurguer
```

### 2. Instale as dependências

```bash
npm install
# ou
yarn install
# ou
pnpm install
# ou
bun install
```

---

## ▶️ Como Executar

### Modo Desenvolvimento

```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev
```

A aplicação estará disponível em [http://localhost:3000](http://localhost:3000)

O projeto utiliza **hot reload**, então as alterações são refletidas instantaneamente enquanto você edita os arquivos.

### Modo Produção

```bash
npm run build
npm start
```

## 🚀 Deploy

### Vercel (Recomendado)

O StalkerBurguer está configurado para deploy automático no Vercel. Para fazer deploy da sua própria instância:

1. Faça push do seu código para um repositório GitHub
2. Conecte o repositório no [Vercel Dashboard](https://vercel.com/dashboard)
3. O deploy será automático a cada push na branch principal

Para mais informações, consulte a [documentação de deploy do Next.js](https://nextjs.org/docs/app/building-your-application/deploying)
